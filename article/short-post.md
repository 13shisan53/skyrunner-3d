## 版本 A｜小红书 / 朋友圈（约 300 字）

**用 1200 行代码，做了个能在手机上玩的 3D 平台游戏 🎮**

没有 Unity，没有美术素材，没有一首音频文件。
只有一个 HTML 文件 + 一个 JS 模块 + three.js。

✅ 桌面：WASD + 空格，鼠标转视角
✅ 手机：左边虚拟摇杆，右边跳跃键
✅ 无尽模式：平台随机生成，跑得越远分越高
✅ 踩无人机 +2 金币，掉下去就结束

踩过的两个坑，比代码本身有意思：

1️⃣ 跳跃手感 = 土狼时间 0.11 秒 + 输入缓冲 0.12 秒 + 下落重力加倍。
少任何一个，角色都像一块砖。

2️⃣ 加触屏那天，手机打开是**一整片黑屏**。
查了半天发现：CSS 里 `.touch { display: none }` 把 `<body>` 自己隐藏了——
因为 JS 给 body 也加了 `touch` 类。

改一个类名，世界安静了。

🎨 角色、平台、天空、金币全部是代码画的；
🎵 背景音乐也是代码合成的（原本想用《花之舞》，版权原因改成原创了）。
