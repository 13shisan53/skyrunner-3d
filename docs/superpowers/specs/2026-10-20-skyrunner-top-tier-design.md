## 0. 摘要

v1.0 证明了"289KB 也能跑 3D 平台游戏"，但没证明"这游戏好看、顺、让人想再玩"。三个硬伤：

1. **画面像原型**：纯色圆角盒子、平板天空、没有景深、没有环境生命。
2. **帧率不可控**：软渲染 14fps，固定开 Bloom + 2048 阴影 + DPR 2，没有降级路径；`dt` 被 clamp 到 1/30，卡顿时动作会"跳"。
3. **留不住人**：结算只说"你死了"，没有"差多少"；没有连击、没有解锁、没有每日；失败后没有具体理由再开一局。

v1.1 保留 PRD 里已验证的手感参数与无尽生成骨架，重做**视觉纵深、帧率稳定性、动作连贯性、差一点钩子**四件事。

一句话：**让玩家在 10 秒内觉得"这不像网页"，在 60 秒内觉得"再来一次就有了"。**

## 1. 意图与成功标准

### 1.1 为什么做

- 用户明确的对标：腾讯系小游戏——**简单易上手、不枯燥、越玩越想玩**。
- 用户明确的失败条件：**页面简单、内容卡顿、动作不连贯**。这三条直接判死刑。
- 现有 v1.0 正好三条都踩：页面平、软渲染 14fps、相机硬跟 + dt 截断。

### 1.2 成功标准

| 维度 | v1.0 现状 | v1.1 目标 | 验证方式 |
|---|---|---|---|
| 第一眼 | 纯色平台 + 渐变天空 | 有云海、远岛、阳光、粒子、环境在动 | 截图 + 人工对照 |
| 帧率 | 软渲染 14fps | 720p 真 GPU 稳定 60fps；p99 帧 < 25ms | `test/perf.mjs` 实录 |
| 卡顿 | 无降级，首跳编译卡顿 | 自适应三档；60 秒内 0 个 > 50ms 长帧（启动预热除外） | 帧时间直方图 |
| 连贯 | dt 截断、相机硬跟 | 120Hz 固定步长物理 + 渲染插值；相机弹簧；落地/转身有过渡 | 录屏 + 逐帧检查 |
| 上手 | 需要 WASD 才会跑 | 自动向前，只需要"跳"和"微调左右" | 5 人测试首次跳跃 < 5s |
| 重玩 | 结算只有分数 | 结算第一行是"差 118 分"；解锁差几枚；每日挑战 | 5 人测试 ≥ 3 人主动重开 |
| 技术 | 单文件 1057 行 | 模块拆分；单元测试 + E2E + 性能报告全绿 | `npm test` 等价命令 |
| 移动端 | 触屏可用，无性能数据 | 390×844 功能通过；性能靠自动降档，不作为本轮 60fps 门槛 | E2E 移动端用例 |

> 5 人测试本轮不执行（没有真实用户），但所有为它准备的钩子必须在：首次跳跃计时、重开计数、单局时长记录。

### 1.3 非目标

排行榜、账号、云存档、广告、内购、关卡编辑器、多人、原生 App、写实画面、超过 5 分钟的内容量。

### 1.4 反目标（做成了也算失败）

- 用随机数制造失败，让玩家觉得"游戏耍赖"。
- 假"差一点"：把失败线做宽再卖复活，或结算文案夸大。
- 用数值 grind 换留存（反复刷同一局攒金币）。
- 为视觉堆全屏效果，牺牲帧率。
- 强 FOV 拉伸、强震屏导致眩晕。
- HUD 帧率显示虚高，掩盖真实性能。

## 2. 核心体验

### 2.1 一句话

**踩着浮空平台穿过云海，只做一件事——跳；每一次落地都比上一次更险、更准、更连。**

### 2.2 单局节拍（目标 45–75 秒）

| 时间 | 发生什么 | 玩家应该感到 |
|---|---|---|
| 0–2s | 已经在跑，第一块平台很宽，屏幕只有"跳"一个提示 | 我会 |
| 2–10s | 第一串金币、第一个 2m 缺口、第一次落地反馈 | 简单，但手感很贵 |
| 10–30s | 连击开始累积，第一只无人机，第一次"险落"加成 | 有点东西 |
| 30–55s | 换天色，速度提升，护盾出现，HUD 提示"离纪录还差 312" | 再撑一会就破了 |
| 55–75s | 在最高速段掉落；慢镜头；结算"差 118 分" | 不甘心 |
| 重开 | 0 加载、0 确认，按键即跑 | 再来 |

### 2.3 情绪曲线

紧张来自**速度 + 缺口 + 连击不能断**；释放来自**险落/擦身/踩杀的慢镜与音效**；不甘来自**结算的差值**。三者每 10 秒至少循环一次。

## 3. 控制与手感

### 3.1 自动向前（我的决定）

v1.0 需要按住 W 才跑。v1.1 改为**自动前进**：玩家只需要横移和跳。理由：

- "简单易上手"要求第一秒就在发生事情，而不是先学按键。
- 单拇指场景下，少一个持续按住的动作。
- 速度曲线由系统控制，难度更可控，"差一点"更容易设计。

**方向约定（避免拖视角把操作拧反）**：

- 赛道永远沿世界 **+Z** 延伸；自动前进是 +Z，横移是 **±X**。移动与相机朝向无关。
- 鼠标/手指拖拽只改变**观看角度**，不改变移动方向；跑动中水平旋转限制在 ±20°，松手 1.2 秒后回到正后方。
- 摇杆的 Y 轴不产生前后移动（已自动前进），避免和 X 轴抢输入。

### 3.2 输入

| 平台 | 横移 | 跳 | 其它 |
|---|---|---|---|
| 桌面 | `A/D` 或 `←/→` | `空格`（按住更高） | `R` 重开，`Esc` 暂停，`M` 静音，鼠标拖拽转视角 |
| 手机 | 左下摇杆（只用 X 轴） | 右下跳跃键；右半屏点按也可跳 | 空白处拖拽转视角；水平限 ±20°；安全区适配 |

**不做**双击跳、二段跳、滑铲。一个动词。

### 3.3 数值（沿用 PRD 已验证项，新增项标注）

| 参数 | 值 | 来源 |
|---|---|---|
| 前进速度 | 6.8 → 10.8 m/s（45 段内线性） | 新 |
| 跳跃初速 | 12.6 m/s | PRD `[代码]` |
| 上升/下落重力 | 34 / 46 m/s² | PRD `[代码]` |
| 土狼时间 | 0.11s | PRD `[代码]` |
| 跳跃缓冲 | 0.12s | PRD `[代码]` |
| 横移加速度 | 地面 55 / 空中 26 m/s² | 新 |
| 横移最大速度 | 6.0 m/s | 新 |
| 碰撞半径/半高 | 0.36 / 0.55 | PRD `[代码]` |
| 平台边缘容错 | 0.12m（视觉边缘外仍可站） | 新 |
| 落地挤压 | 0.72 → 1，90ms 回弹 | 新 |
| 相机 FOV | 58° → 66°（随速度） | 新 |

**开局与重开**：1.2 秒内速度从 0 线性升到 6.8 m/s；第一块平台进深 22m，第一个缺口在 11m 处。点下"开始"不会立刻被缺口惩罚，镜头也有时间从首页环绕过渡到背后跟随。

### 3.4 "动作连贯"的具体定义

- **固定步长物理 120Hz**，渲染帧用 `alpha` 在前后状态间插值；卡顿时动作变慢，而不是瞬移。
- **输入在物理步内消费**，跳跃缓冲保证"按早了也算"。
- **相机用临界阻尼弹簧**，跟随位置/朝向/距离分别有阻尼，禁止 `lookAt` 硬切。
- **角色朝向按角速度插值**，横移时身体侧倾 ≤ 12°。
- **动画速度绑定真实速度**，不绑固定时钟；落地有 90ms 的压缩-回弹混合。
- **任何 UI 动画只用 transform/opacity**，不触发布局。
- 掉帧时**优先降分辨率与后期**，不降物理频率、不截断输入。

## 4. 世界与生成

### 4.1 生成语法

不再"每段都是同一种盒子"。每 1–3 段组成一个"词组"，按难度加权抽取：

| 原型 | 形态 | 作用 |
|---|---|---|
| 宽台 | 9–11m 宽，短缺口 | 呼吸段，放金币线 |
| 窄桥 | 4.4–6m 宽，长 12–16m | 测横移，放无人机 |
| 双踏石 | 两块 3.5–5m，前后错位 | 连续两次跳 |
| 长桥+巡逻 | 12m 长，无人机横向巡逻 | 踩杀或绕行 |
| 阶梯 | 3 块逐级 +0.8m | 节奏变化 |
| 孤岛+金币弧 | 5m 台，金币抛物线 | 风险收益 |

### 4.2 公平性硬规则

- 最大缺口 ≤ 当前速度下 85% 跳跃射程。
- 下一块平台中心必须在 1.2 秒内可横移到达。
- 无人机不生成在落点边缘 1.5m 内。
- 前 3 段无无人机、无窄桥。
- 每个缺口上方至少有一条"安全金币线"，不强迫贪心。
- 难度在第 45 段封顶（PRD 原则：挫败感来自操作，不来自随机数）。

### 4.3 群系

每 18 段（约 28–32 秒）切换一次，2.5 秒过渡：晨光 → 正午 → 黄昏 → 星夜。每个群系改变天空、雾、阳光、平台色板、环境粒子、音乐层。一局通常能看到 2–3 个群系。

### 4.4 生成与回收

前方 80m 补齐，身后 34m 回收；几何按尺寸分桶缓存，材质按颜色缓存；回收时 `dispose` 只处理独立几何。

### 4.5 随机与种子

普通局用 `Math.random`；每日挑战用 `mulberry32(YYYYMMDD)`，保证同一台设备当天路线相同（无排行榜，但成绩可与自己比较）。日期按**本地时区**计算。暴露 `start(seed)` 供测试。

## 5. 计分、连击与"差一点"

### 5.1 计分

```
score = floor(最大前进距离) × 10
      + 金币分（每枚 100 × 拾取时倍率）
      + 技巧分（险落 +150，擦身 +80）
```

基础式与 PRD 一致；金币倍率与技巧分是新增层，HUD 分开显示来源，不藏。

### 5.2 连击

- 连击只由事件累加：吃金币、踩无人机、险落、擦身。普通落地不加。
- 倍率 = `1 + floor(streak / 8)`，上限 5。
- 6 秒没有新增连击后开始衰减：每 0.75 秒 -1，直到 0；被撞直接清零。这样"断连"是逐渐发生的，玩家有时间救回来。
- HUD 有环形连击条；倍率变化有音高与数字弹跳。

### 5.3 五个"差一点"装置

1. **纪录追标**：HUD 显示"离纪录还差 312"；到 90% 时变色；破纪录瞬间全屏金色粒子 + "新纪录"。
2. **险落**：落点距平台**前进方向前缘** < 0.35m，且本次滞空 > 0.25s、平台进深 > 4m → "险落 +150"、慢镜 0.12s、连击 +1。每块平台只触发一次，防止短平台上刷分。
3. **擦身**：未发生碰撞，且与无人机中心 3D 距离 < 1.2m → "擦身 +80"、连击 +1。每只无人机只触发一次。
4. **护盾**：每 12–16 段在平台上方生成一个泡泡，拾取后获得一次侧撞免疫（HUD 显示环）。侧撞消耗护盾、击退，但不掉连击；无护盾时侧撞掉连击并击退，不死亡。这让"差点完蛋"有一次可感知的回头。
5. **结算差值**：第一行大字是"差 118 分"；差距 < 5% 时文案换成"就差一点"；新纪录则显示"+86"。

### 5.4 失败与重开

- 仅掉落到 `y < -18` 判负；侧撞不死（护盾/击退）。
- 死亡时间线：80ms 顿帧 → 0.25× 慢镜 0.15s → 相机跟落 1.1s → 结算面板 0.35s 淡入。
- 面板出现 0.5s 后，任意跳跃键/回车可跳过动画直接重开。
- 重开：清场、重置玩家、立即生成，无加载、无确认。
- 最高分写 `localStorage`；同时记录本局距离、金币、最高连击、时长、死因。

### 5.5 结算面板内容（从上到下）

1. 差值大标题（"差 118 分" / "就差一点" / "新纪录 +86"）。
2. 数值行：得分、距离、金币、最高连击。
3. 纪录进度条（本局 / 历史最高）。
4. 最接近的解锁："再 7 枚金币解锁「霞光」"。
5. 今日任务进度（3 条，完成的打勾）。
6. 主按钮"再来一次"，次按钮"回到主页"。

## 6. 成长与"意犹未尽"

### 6.1 金币经济（纯外观）

金币跨局保留。可解锁：

| 类型 | 内容 | 价格 |
|---|---|---|
| 角色 | 默认「青」 / 「霞」 / 「夜」 / 「金」 | 0 / 60 / 150 / 300 |
| 拖尾 | 无 / 星尘 / 彩虹 / 火焰 | 0 / 40 / 120 / 240 |

角色只改配色、围巾与头顶配件，不改数值。解锁即选中。

**防刷规则**：每日挑战当天第 1 次尝试正常结算金币与任务进度；之后的尝试只计分数与"今日最佳"，不再产出金币或任务进度。固定路线因此不能被当成刷币机。

### 6.2 每日任务

每天 3 条，从池中按日期确定性抽取：吃 40 金币、踩 3 只无人机、单局 600m、5 次险落、单局 8 连击。奖励 40/60/80 金币。进度跨局累计，按日期存。

### 6.3 每日挑战

首页有"今日挑战"卡片，显示今日最佳。固定种子（本地日期 `YYYYMMDD`），路线相同，可反复尝试；只有当天第 1 次尝试结算金币与任务进度。与普通局分开记录最佳。

### 6.4 记录与"再来一局"的理由

首页显示：历史最高、最近 10 局迷你折线、总里程、最高连击。每次死亡必须能回答"为什么再来"：差多少分、差几枚金币、哪个任务差一点。三个里至少命中一个。

## 7. 视觉方向

### 7.1 三个支柱

1. **云海纵深**：近景平台、中景云层、远景岛屿、天空四层，任何一帧都有远近。
2. **纸艺糖果**：圆角、厚边、双色、软阴影，不做写实材质。
3. **光线会变**：一局里天色真的会换，颜色是节奏的一部分，不是滤镜。

### 7.2 色彩脚本

| 群系 | 天空顶/中/底 | 雾 | 阳光 | 平台主色 | 环境粒子 |
|---|---|---|---|---|---|
| 晨光 | `#2b3a67` / `#ff9e7a` / `#ffe7c7` | `#f7c6a3` | `#ffd9a0` | 珊瑚/杏/薄荷/天蓝 | 花瓣 |
| 正午 | `#1f6fd0` / `#8fd0ff` / `#eaf7ff` | `#cfe9ff` | `#fff6d8` | 糖果七色 | 浮尘 |
| 黄昏 | `#2a1e5c` / `#ff5f7e` / `#ffc98a` | `#d98a9a` | `#ff8a5c` | 暖粉/橙/紫 | 萤火 |
| 星夜 | `#050a1e` / `#1a2a5e` / `#3d5a8a` | `#14203c` | `#cfe4ff` | 深色 + 发光边 | 星尘 |

平台在红绿色盲模拟下不能只靠颜色区分：每块平台顶面有一个低对比度形状标记（● / ▲ / ■ 轮换），并且相邻平台色相至少差 60°。

### 7.3 场景层

- **天空**：单球体 shader，三色渐变 + 太阳/月亮圆盘 + 光晕 + 夜间 300 颗星（点精灵）。
- **云**：三层共 54 个 billboard 云团（canvas 径向纹理），不同速度视差；近层受雾影响，远层降低透明度。
- **远岛**：10 座低多边形岛，合并成一个几何体，顶点色，无阴影，缓慢上下浮动。
- **平台**：圆角盒 + 顶面浅色 + 侧面暗色 + 边缘亮条；上下浮动 ±2cm；落地时一圈涟漪。
- **环境**：200 个尘埃/花瓣/萤火粒子，围绕相机循环，按群系换色。

### 7.4 角色

保留圆头 + 青色连体服，增加：

- 围巾（两段 ribbon，按速度波动）；
- 背包与天线灯（呼吸发光）；
- 眨眼（3–6 秒随机）、看向下一块平台；
- 跳跃前预蹲 60ms、空中收腿、落地压缩；
- 横移侧倾；被撞后 0.3s 僵硬与闪烁无敌。

### 7.5 特效（全部池化，最多 240 粒子）

落地尘环、起跳尘、金币吸附与拾取爆点、踩杀冲击环、护盾破裂、破纪录金色雨、高速风线、死亡慢镜暗角。

### 7.6 镜头语言

- 首页：绕场景缓慢环绕，FOV 55°，角色待机呼吸。
- 跑动：弹簧臂跟随后方 7.6m（竖屏 9.6m），看向前方 4m；横移时轻微侧移，不晃。
- 速度感：FOV 58→66，风线密度随速度；震屏上限 0.15，落地/踩杀才触发。
- 死亡：慢镜、镜头下沉、轻微拉远，不旋转。

### 7.7 UI / 页面

**首页不是一张说明卡，是一个活着的场景**：游戏画面在背后缓慢运动，前面是玻璃质感的标题与卡片。

- 标题：渐变字 + 轻微漂浮 + 进入时 400ms 上浮淡入。
- 主按钮"开始"：唯一高饱和色块；下方一行小字"只有一个动作：跳"。
- 首页卡片：最高分、今日挑战、最近 10 局折线、设置齿轮。
- HUD：左上分数（数字滚动）、连击环、金币、距离；右上暂停/静音；底部中间"离纪录还差 312"。
- 提示：里程碑 toast 从右侧滑入（"200m · 进入黄昏"），2.2s 自动消失。
- 结算：暗角 + 面板从下方 24px 上浮；差值标题 48–64px；按钮有按压位移。
- 设置：半屏抽屉，含低刺激、减少动态、画质、音效、音乐、本地统计、语言、重置数据。

## 8. 音频

### 8.1 音效（WebAudio 合成，无文件）

跳跃（随连击升调）、落地（按冲击力分三档）、金币（五声音阶上行）、踩杀、护盾破裂、险落提示、破纪录、死亡、UI 点击、倒计时滴答。

### 8.2 音乐

92 BPM，Dmaj9–Bm9–Gmaj9–A9 循环，四层：pad、钢琴琶音、贝斯、hi-hat。层数随速度和连击增加；死亡时 0.2s 内 duck 到 20%；静音状态持久化。

这是对 v1 固定循环的**重写**，不是沿用：复用 v1 的振荡器/滤波器合成方式，但把"每层一个 gain 节点、按强度开关"做成可调度的配器。音频属于本轮 P0，因为"不卡顿、不廉价"的一半来自声音。

## 9. 技术方案

### 9.1 模块

| 文件 | 职责 |
|---|---|
| `src/main.js` | 启动、状态机、固定步长循环、渲染编排 |
| `src/config.js` | 所有常量、群系、色板、难度曲线 |
| `src/strings.js` | zh-CN / en 文案，全部用户可见文案从这里取 |
| `src/gen.js` | 纯生成：种子 RNG、赛道语法、公平性约束 |
| `src/score.js` | 计分、连击状态机 |
| `src/physics.js` | 运动学 AABB、逐轴解算、边缘容错 |
| `src/input.js` | 键盘/触屏/拖拽，统一成 `{ steer, jumpPressed, jumpHeld }` |
| `src/player.js` | 玩家状态、物理、碰撞、角色 rig 与动画 |
| `src/world.js` | 生成、回收、平台/金币/无人机/护盾、种子 RNG |
| `src/camera.js` | 弹簧臂、FOV、震屏、菜单环绕、死亡镜头 |
| `src/fx.js` | 粒子池、风线、飘带、屏幕反馈 |
| `src/audio.js` | 合成音效与分层音乐 |
| `src/quality.js` | 帧时间采样、三档降级/恢复、持久化 |
| `src/meta.js` | 存档、解锁、任务、每日种子、统计 |
| `src/ui.js` | HUD、首页、结算、设置、锁定面板、toast |
| `src/analytics.js` | 本地事件记录（不联网） |

`index.html` 只留壳、样式与 import map。仍然无构建步骤。

### 9.2 循环

```
rAF:
  frameDt = clamp(now - last, 0, 0.1)
  accumulator += frameDt
  while accumulator >= 1/120:
    fixedUpdate(1/120)      // 输入、物理、碰撞、拾取、计分
    accumulator -= 1/120
  alpha = accumulator / (1/120)
  render(alpha)             // 插值玩家/相机/实体，更新视觉
```

### 9.3 画质分档

| 档 | DPR | 阴影 | Bloom | 云 | 粒子 | 抗锯齿 |
|---|---|---|---|---|---|---|
| 高 | min(DPR, 2) | 1024 | 开（半分辨率） | 54 | 240 | 开 |
| 中 | 1.25 | 512 | 开（低强度） | 36 | 140 | 开 |
| 低 | 1.0 | 关 | 关 | 20 | 80 | 关 |

采样最近 120 帧；p95 > 22ms 持续 2s 降一档；p95 < 14ms 持续 8s 升一档；有滞后避免抖动。设置里可选"自动/高/中/低"。

### 9.4 预算

| 项 | 预算 | 测量 |
|---|---|---|
| 首屏传输（gzip） | ≤ 350KB | CDP Network |
| 应用 JS（不含 three） | ≤ 70KB | 文件大小 |
| Draw calls | ≤ 140 | `renderer.info.render.calls` |
| 三角形 | ≤ 120k | `renderer.info.render.triangles` |
| 帧时间 p99 | ≤ 25ms（720p 真 GPU） | `test/perf.mjs` |
| 长帧 > 50ms | 预热后 0 个 | 同上 |
| JS 堆 | ≤ 40MB | `Performance.getMetrics` |

**验收环境**：本机 Chrome 155 / AMD Radeon 610M 集显 / 1280×720 / DPR 1 / 非 headless。移动端只做功能验收与自动降档，不以模拟器帧率作为 60fps 门槛；真机性能是 v1.2 的独立任务。

### 9.5 稳定性

- 启动时 `renderer.compile` + 空跑 2 帧，避免首跳编译卡顿。
- 后期管线在首页之后再动态 import；未就绪时直接渲染。
- 所有 hot loop 不新建对象；金币/无人机/粒子用池与 swap-pop。
- 全局错误捕获显示可读错误层，禁止白屏。
- `beforeunload` 不拦截；页面隐藏时暂停音乐与计时。

### 9.6 存储

`localStorage` 键 `skyrunner.save.v2`，JSON：

```json
{
  "best": 0, "coins": 0, "unlocked": ["char.default"], "worn": {"char":"char.default","trail":"trail.none"},
  "settings": {"quality":"auto","lowStim":false,"reduceMotion":false,"sound":true,"music":true,"locale":"zh-CN","localStats":true},
  "daily": {"date":"2026-10-20","best":0,"attempts":0},
  "missions": {"date":"2026-10-20","items":[{"id":"coins40","progress":12,"done":false}]},
  "runs": [{"score":0,"dist":0,"coins":0,"combo":0,"duration":0,"cause":"fall","at":0}]
}
```

损坏或旧版本时安全回退默认值，不抛异常。

### 9.7 本地统计与隐私

- 默认只写本机 `localStorage`，**不发起任何网络请求**。
- 事件：`session_start`、`run_start`、`run_end`、`restart_click`、`leave`。
- 设置里"本地统计"可关；关闭后不写事件（保留最高分等必要存档）。
- `privacy.html` 说明采集项、目的、保留期（最近 200 条，30 天后只留聚合）、关闭方式。
- 不采集 UA 全串、不采集 WebGL 渲染器字符串、不做指纹。

### 9.8 无障碍

- 低刺激：关 Bloom、关震屏、降闪光、粒子减半。
- 减少动态：关相机 FOV 变化与 UI 位移动画。
- 高对比：HUD 文本 ≥ 7:1；平台形状标记。
- 键盘全流程可玩；焦点可见；按钮原生 `<button>`；`aria-label`。
- 无 > 3Hz 闪烁；破纪录金色雨为一次性，不循环。
- `prefers-reduced-motion` 自动映射到"减少动态"。

### 9.9 i18n

全部文案走 `strings.js`；`locale` 默认 `zh-CN`，检测 `navigator.language` 以 `zh` 开头否则 `en`。切换后不重载页面，重建 UI 文案。英文长度按 1.4× 预算，按钮不换行。

## 10. 测试

### 10.1 单元测试（node:test）

- 种子 RNG 确定性（同种子 100 次序列一致）。
- 生成公平性：500 个种子 × 60 段，无不可达缺口、无落点边缘无人机。
- 计分与连击：倍率边界、6 秒后逐级衰减、被撞清零。
- 每日种子：同一本地日期稳定，跨日期变化；首次尝试与复玩的金币/任务产出规则。
- 画质分档：给定帧时间序列，降/升档时机正确，无抖动。
- 文案完整性：zh 与 en key 集合一致。
- 存档：旧版/损坏 JSON 回退不抛异常。

### 10.2 E2E（CDP）

1. 冷启动无致命错误，`body.dataset.ready` 置位。
2. 首页可见，开始按钮可点。
3. 开始后 500ms 内模式为 `play`，角色自动前进。
4. 横移改变 x 且仍站在平台上。
5. 跳跃 y 上升；按住比点按高。
6. 吃金币：金币 +1、连击 +1、分数增加。
7. 踩无人机：+2 金币、反弹、连击增加。
8. 侧撞：不死亡、连击清零、护盾消耗。
9. 险落：触发技巧分与提示。
10. 普通缺口可通过（脚本按固定节奏跳，跑 800m 不死）。
11. 掉落后进入 `over`，结算差值文案正确。
12. 新纪录写入并显示。
13. 重开：模式回 `play`、分数归零、位置重置。
14. 暂停：`Esc` 后物理停止，恢复后继续。
15. 设置持久化：低刺激开关刷新后仍生效。
16. 每日挑战：同一天两次开始，前 5 块平台坐标一致。
17. 解锁：给足金币后可解锁并穿上。
18. 移动端：390×844 触屏 UI 出现、摇杆可移动、跳跃键可跳。
19. 无未捕获异常、无 console error。
20. 低刺激模式下 Bloom pass 关闭。
21. 每日挑战第 2 次尝试不再增加金币与任务进度。
22. 页面隐藏时暂停，恢复后继续；音频不叠加。

### 10.3 视觉

桌面 1280×720 与移动 390×844 各截：首页、跑动中、黄昏、星夜、险落、结算、设置。共 ≥ 10 张，人工检查构图与可读性。

### 10.4 性能

- 非 headless Chrome、720p、真 GPU：跑 60 秒脚本局，记录 p50/p95/p99、长帧、draw calls、内存。
- CPU 6× 节流下：10 秒内自动降到"低"档且不崩溃。
- 软渲染：仅验证可运行与降级，不作为 60fps 判定。

### 10.5 验收门槛（DoD）

- 单元 + E2E 全绿。
- 性能：p99 ≤ 25ms、预热后 0 长帧、draw calls ≤ 140。
- gzip 首屏 ≤ 350KB。
- 截图齐全，人工检查通过。
- 无 console error；移动端触屏通过。
- PRD 里 v1.0 已通过的 11 项功能验收不回退。

## 12. 我替你做的决定

1. **自动向前**，把操作减到"跳 + 横移"。
2. **美术走"纸艺糖果 + 云海"**，不做写实，不用外部模型。
3. **计分在 PRD 基础上加金币倍率与技巧分**，基础公式不变。
4. **侧撞不死**，只掉连击/护盾；死亡只来自掉落。
5. **拆模块，但保持无构建**；继续用 three.js r160。
6. **只做本地存档与本地统计**，不联网。
7. **名字继续叫 SKYRUNNER**，不换 IP。
8. **性能优先于特效**：任何效果都必须有三档降级。
9. **赛道固定沿 +Z，相机只做观看**；横移固定 ±X，拖拽只改视角并自动回正。
10. **每日挑战只有当天第 1 次产出金币与任务进度**，之后只计分，防止固定路线被刷。
11. **连击只由事件累加**（金币/踩杀/险落/擦身），6 秒后逐级衰减，不是"每次落地都 +1"。
12. **音频按 §8 重写四层配器**，不沿用 v1 的固定循环。
13. **性能验收只对 720p 真 GPU 负责**；移动端功能验收 + 自动降档，真机性能留到 v1.2。
